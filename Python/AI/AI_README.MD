# SlimHealth AI 모델

## 개요
국민건강보험공단 건강검진 데이터(2012~2024) 기반
체중 감량 시 대사증후군 5대 지표 변화 예측 XGBoost 모델

## 데이터
- 원시데이터: 국민건강보험공단 건강검진정보 2012~2024 (1,300만행, 연령대 필터링 하면서 13개년 데이터 통합 실시 -> 7,860,223행)
- 전처리 후: 4,847,486행 (30~50대)
- 더미데이터: 9,905,232행 (BMI 9구간별 시계열 생성)

## 실행 순서
1. STEP 0~1: 원시데이터 로드 및 전처리
2. STEP 2: 의학 계수 테이블 정의 (COEF)
3. STEP 3: BMI 9구간별 시계열 더미데이터 생성
4. STEP 4: 더미데이터 검증 (5항목)
5. STEP 5: 피처/타겟 정의 및 학습/검증 분리
6. STEP 6: XGBoost 학습
7. STEP 7: 모델 저장 (health_models_v6.pkl)
8. STEP 8: 시뮬레이터 함수 정의
9. STEP 9: 시뮬레이터 테스트
10. STEP 10: 원시데이터 교차검증
